# Express + Mongoose starter

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and set `MONGODB_URI` to your MongoDB connection string and `JWT_SECRET` to a long, random secret.
3. Start the development server with automatic reload: `npm run dev`

The server connects to MongoDB before listening on the configured `PORT` (default `3000`). Check `http://localhost:3000/` for the starter response.

Use `npm start` to run without nodemon.
